# V9 - Prévia antes/depois, edição do portfólio atual e log

Incluído:
- Prévia comparativa: como está agora x como ficará após salvar.
- Botão para sincronizar o portfólio atual do site a partir do main.js.
- Edição dos itens importados do portfólio pelo painel.
- Botões de subir/descer para ordenar itens do portfólio e seções.
- Log de modificações salvas em content/change-log.json no R2.
- Loader do site renderizando portfólio a partir do JSON quando houver itens cadastrados.

Importante:
Para salvar e registrar logs, o R2_BUCKET precisa estar configurado no wrangler.toml com o nome real do bucket.
