Etapas da timeline

Reels

Preparado para vídeo, segmento, ordem e thumb automática/manual.


Cards

Preparado para imagem, título, segmento, categoria e ordem.


Carrosséis

Preparado para múltiplos slides com ordem fixa, como você pediu.


Feedbacks

Preparado para nome, cargo, texto, nota, foto/logo, ordem e ativar/desativar.


Biblioteca de mídia

Envie imagens e vídeos para o R2 e escolha o destino. Depois o arquivo pode ser vinculado a reels, cards, carrosséis, clientes, feedbacks ou bio.



Editor avançado

Use quando precisar ajustar listas grandes, carrosséis ou estruturas novas.


Acesso do painel

O token fica salvo apenas no seu navegador. Configure o mesmo valor em Settings → Environment variables → ADMIN_TOKEN.


Configuração Cloudflare

Você precisa configurar o binding R2_BUCKET no Cloudflare Pages e, opcionalmente, PUBLIC_R2_BASE_URL para gerar URLs públicas das mídias.
